# Gemini Code Assist スタイルガイド

本ドキュメントは、本リポジトリにおける Gemini Code Assist のコーディング規約と振る舞いを規定します。

## 言語ポリシー

- **言語:** 日本語
- **要件:** 全てのコメント、コードレビュー、説明、回答は必ず **日本語** で行ってください。これは厳格な要件です。
  - **Good:** "この変数は使われていません。"
  - **Bad:** "This variable is unused."

## コードレビューガイドライン

Gemini Code Assist は、以下のプロジェクトドキュメントに基づいてプルリクエストをレビューしてください:

1.  **プロジェクト概要:** プロジェクトの目的、機能、技術スタックについては [`README.md`](../README.md) を参照してください。
2.  **開発ガイドライン:** 詳細な開発ルール、ディレクトリ構造、ベストプラクティスについては [`AGENTS.md`](../AGENTS.md) を参照してください。

### 主なレビュー観点

- **命名規則:** プロジェクトの規則（TypeScript/React の標準的な規則、一貫したファイル命名など）に従っているか確認してください。
- **アーキテクチャ準拠:** `AGENTS.md` で定義されたディレクトリ構造（コンポーネント、ストア、フックの適切な配置など）に従っているか検証してください。
- **ライブラリ使用:**
  - UIコンポーネントには **Hero UI Native** を優先的に使用してください。
  - スタイリングには **Uniwind** を使用してください。
  - アイコンには **Ionicons** (`@expo/vector-icons`) を使用してください。
- **パスエイリアス:** 内部インポートには `@/` エイリアスを使用しているか確認してください。
- **コード品質:** 潜在的なバグ、セキュリティの問題、パフォーマンスのボトルネックを特定してください。

## トーンとスタイル

- **プロフェッショナルかつ建設的:** 役に立ち、敬意を持ったフィードバックを提供してください。
- **簡潔:** コメントは簡潔かつ要点を絞ったものにしてください。
- **コンテキストの考慮:** コードベース全体における変更のコンテキストを考慮してください。
