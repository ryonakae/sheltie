# Sheltie

![ボードに並べた複数の Web ページを見比べるシェルティ](.github/assets/readme-hero.png)

Sheltie は、動いている Web ページをそのまま無限キャンバスに並べられる macOS アプリです。デザインツールでアートボードを眺めるように、サイト全体を俯瞰して確認できます。

## Sheltie を作った理由

![ポートフォリオサイトの各ページを並べ、矢印と付箋で注釈した Sheltie のボード](.github/assets/readme-screenshot.png)

AI コーディングエージェントを使って最初からコードでプロトタイプを作り、動くもので検証するチームが増えています。コードを書かないデザイナーが、AI に頼んで自分で Web アプリを作ることも珍しくなくなりました。

ただ、ブラウザで確認できるのは一度に1ページだけです。複数の画面にまたがるトンマナや余白感、タイポグラフィ、ページ間の導線は、俯瞰して見ないと判断できません。1ページずつ開いて確かめるのは手間がかかり、ここだけは今も Figma や Sketch のアートボードが頼りになります。

そのすき間を埋めるために作ったのが Sheltie です。ブラウザとデザインツールのちょうど中間のような位置づけのツールで、Web ページをキャンバスに並べ、ズームアウトすれば全体を俯瞰でき、ズームインすればページを直接操作することができます。

## できること

- **動いているページをそのまま並べる:** ボードに置いた Web サイトは、1枚ずつがネイティブ Webview（Safari と同じ WebKit エンジン）です。ブラウザと同じ感覚でスクロールもクリックもできます。
- **引いて眺める:** ボード全体をパン・ズームしながら見れば、画面をまたいだ余白・タイポグラフィ・配色のばらつきがひと目で分かります。
- **導線を描く:** ページ同士を矢印でつないで遷移の流れを図示し、付箋やテキストでメモを残せます。
- **ボードの保存と共有:** ボードは `.sheltie` ファイルとして保存できます。ファイルなので、Git で管理することもできます。複数のボードは macOS ネイティブのウィンドウとタブで扱います。
- **コーディングエージェントと組み合わせる:** ローカル MCP サーバーを内蔵しています。Claude Code などのエージェントに画面を直してもらい、すぐボード上で見比べる、という使い方ができます。エージェントが Sheltie の使い方を理解するための Agent Skill も提供しています。

## インストール

Homebrew でインストールできます。

```bash
brew install --cask ryonakae/tap/sheltie
```

[GitHub Releases](https://github.com/ryonakae/sheltie/releases) から最新の `Sheltie_<version>_universal.dmg` をダウンロードして開き、Sheltie を Applications フォルダにドラッグしても構いません。

どちらも中身は同じユニバーサルバイナリ（Apple Silicon / Intel）で、署名・公証済みです。

対応 OS は今のところ macOS のみです。

## クイックスタート

1. Sheltie を起動して、新しいボードを作ります。
2. Web ページを追加して URL を入れます。ローカルの開発サーバー（`http://localhost:3000` など）でも、公開中のサイトでも構いません。
3. ページを増やしてドラッグで並べ、ズームアウトして導線を眺めます。
4. ページ同士を矢印でつなぎ、気になったところに付箋を置きます。
5. `.sheltie` ファイルとして保存しておけば、続きから再開できます。

## コーディングエージェントとの連携（MCP）

Sheltie は MCP サーバーとしても動き、ボードとページをローカルの AI エージェントから操作できるようになります。**Sheltie › Settings › Enable MCP Server** で有効化し、MCP クライアントにエンドポイントを登録してください。

```json
{
  "mcpServers": {
    "sheltie": {
      "type": "http",
      "url": "http://127.0.0.1:29978/mcp"
    }
  }
}
```

接続したエージェントは、ボードの内容を読み取り、ページを操作し、スクリーンショットを撮れます。

なお、認証はありません。サーバーは localhost だけで待ち受けますが、接続してきたローカルクライアントは無条件に信頼する作りです。有効にするのは、信頼できるマシンだけにしてください。

## 開発

Sheltie は Tauri v2 + React + TypeScript + Tailwind CSS v4 で作っています。

```bash
git clone https://github.com/ryonakae/sheltie.git
cd sheltie
npm install
npm run dev
```

Node.js 22 と Rust（バージョンは `mise.toml` で固定）が必要です。設計の詳細や開発ルールは [AGENTS.md](AGENTS.md) と [docs/agents/](docs/agents/) にまとめています。
