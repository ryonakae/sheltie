# macOS Icon Pre-commit Automation Implementation Plan

> **For implementers:** Execute this plan task-by-task. Complete each checkbox step, run the listed validation, and commit after all checks pass.

**Goal:** `src-tauri/icons/icon.icon` のステージ済み変更から `Assets.car` を再生成し、同じコミットへ自動追加する。

**Architecture:** 生成処理は再利用可能な POSIX shell スクリプトへ集約する。通常実行では作業ツリー、`--staged` 実行では Git index の tree を一時ディレクトリへ展開して入力にする。Husky の pre-commit は `icon.icon` の staged diff を検出した場合だけスクリプトを呼び、生成した `Assets.car` を index へ追加してから既存検証を続行する。

**Tech Stack:** POSIX shell、Git index、Xcode 26+ `actool` / `assetutil`、Husky、npm scripts

## Global Constraints

- `Assets.car` はコミット対象とし、`icon.icon` と同じコミットに含める。
- pre-commit では作業ツリーではなくステージ済みの `icon.icon` を入力にする。
- Tauri の `.icon` 一時コピー経路は未解決の actool crash があるため使わない。
- `icon.icon` の basename は `icon` であり、`actool --app-icon icon` と一致させる。
- 既存の `.husky/pre-commit` にある lint、typecheck、Vitest、Rust test の順序と成否判定を維持する。
- `git commit --no-verify` では自動生成されないことを運用上明記する。

## Current Context

- `src-tauri/icons/icon.icon` が Icon Composer の編集用ソース。
- `src-tauri/icons/Assets.car` は `actool` で事前生成し、`src-tauri/tauri.conf.json` から参照している。
- `@tauri-apps/cli` は 2.11.4。`.icon` 直接指定は Tauri issue #15315 と同じ crash が再現する。
- `.husky/pre-commit` は `npx lint-staged`、`npm run typecheck`、`npm run test`、条件付き `cargo test --lib` を実行している。
- `src-tauri/icons/*.icon/` は `.prettierignore` に含まれている。

## File Structure

- Create: `scripts/generate-macos-icon.sh` — 作業ツリーまたは Git index の `icon.icon` を `Assets.car` へ変換する。
- Modify: `package.json` — `icon:macos` npm script を公開する。
- Modify: `.husky/pre-commit` — staged icon の変更検出、自動生成、自動 stage を既存検証より前へ追加する。
- Modify: `docs/agents/workflow.md` — 手動生成、自動生成、必要ツール、`--no-verify` の注意を記録する。

## Tasks

### Task 1: Add a reusable macOS icon generator

**Objective:** 同じ生成処理を手動実行と pre-commit の両方から利用できるようにする。

**Files:**
- Create: `scripts/generate-macos-icon.sh`
- Modify: `package.json`

**Interfaces:**
- Consumes: `src-tauri/icons/icon.icon`, optional `--staged`
- Produces: `src-tauri/icons/Assets.car`

- [ ] **Step 1: Record the current failure condition**

Run the staged-mode command before the script exists:

```bash
npm run icon:macos -- --staged
```

Expected: npm reports that `icon:macos` is missing.

- [ ] **Step 2: Add the generator script**

Create `scripts/generate-macos-icon.sh` with this behavior:

```sh
#!/bin/sh
set -eu

repo_root=$(git rev-parse --show-toplevel)
icon_rel=src-tauri/icons/icon.icon
assets_rel=src-tauri/icons/Assets.car
mode=${1:-}
temp_dir=$(mktemp -d)
trap 'rm -rf "$temp_dir"' 0 HUP INT TERM

case "$mode" in
  "")
    icon_path="$repo_root/$icon_rel"
    ;;
  --staged)
    staged_root="$temp_dir/staged"
    mkdir -p "$staged_root"
    tree=$(git -C "$repo_root" write-tree)
    git -C "$repo_root" archive "$tree" "$icon_rel" | tar -x -C "$staged_root"
    icon_path="$staged_root/$icon_rel"
    ;;
  *)
    echo "Usage: $0 [--staged]" >&2
    exit 2
    ;;
esac

if [ ! -d "$icon_path" ]; then
  echo "Icon Composer asset not found: $icon_path" >&2
  exit 1
fi

output_dir="$temp_dir/output"
mkdir -p "$output_dir"
icon_name=$(basename "$icon_path" .icon)

xcrun actool "$icon_path" \
  --compile "$output_dir" \
  --output-format human-readable-text \
  --notices \
  --warnings \
  --output-partial-info-plist "$output_dir/assetcatalog_generated_info.plist" \
  --app-icon "$icon_name" \
  --include-all-app-icons \
  --enable-on-demand-resources NO \
  --development-region en \
  --target-device mac \
  --minimum-deployment-target 26.0 \
  --platform macosx

if [ ! -f "$output_dir/Assets.car" ]; then
  echo "actool did not generate Assets.car" >&2
  exit 1
fi

cp "$output_dir/Assets.car" "$repo_root/$assets_rel"
echo "Generated $assets_rel from $icon_rel${mode:+ ($mode)}"
```

Do not copy the incidental `icon.icns` generated by `actool`; the existing fallback remains independently managed.

- [ ] **Step 3: Add the npm command**

Add to `package.json` scripts:

```json
"icon:macos": "sh scripts/generate-macos-icon.sh"
```

- [ ] **Step 4: Verify working-tree generation**

Run:

```bash

assetutil --info src-tauri/icons/Assets.car | grep '"AssetType" : "Icon Image"'
```

Expected: generation succeeds and `assetutil` prints at least one `Icon Image` entry.

### Task 2: Regenerate and stage Assets.car in pre-commit

**Objective:** staged `icon.icon` changes always bring the corresponding `Assets.car` into the same commit.

**Files:**

**Interfaces:**
- Consumes: Task 1 `npm run icon:macos -- --staged`

- [ ] **Step 1: Add the staged-diff guard before lint-staged**

Insert at the beginning of `.husky/pre-commit`:

```sh
if ! git diff --cached --quiet -- src-tauri/icons/icon.icon; then
  echo "Regenerating Assets.car from staged icon.icon..."
  npm run icon:macos -- --staged
  git add src-tauri/icons/Assets.car
fi
```

Keep all existing validation commands after this block.

- [ ] **Step 2: Verify shell syntax**

Run:

```bash
sh -n scripts/generate-macos-icon.sh
sh -n .husky/pre-commit
```

Expected: both commands exit 0 without output.

- [ ] **Step 3: Verify staged snapshot generation without altering the real index**

Use a temporary index initialized from `HEAD`, stage `icon.icon` into that index, and execute the same hook block:

```bash
real_cached_before=$(git diff --cached --name-only)
test_index=$(mktemp)
rm "$test_index"
GIT_INDEX_FILE="$test_index" git read-tree HEAD
GIT_INDEX_FILE="$test_index" git add src-tauri/icons/icon.icon
GIT_INDEX_FILE="$test_index" sh -c '
  if ! git diff --cached --quiet -- src-tauri/icons/icon.icon; then
    npm run icon:macos -- --staged
    git add src-tauri/icons/Assets.car
  fi
'
GIT_INDEX_FILE="$test_index" git diff --cached --name-only | grep '^src-tauri/icons/Assets.car$'
test "$real_cached_before" = "$(git diff --cached --name-only)"
rm "$test_index"
```

Expected: the temporary index contains `Assets.car`, while the real index is unchanged.

## Validation

- Temporary `GIT_INDEX_FILE` simulation — generated asset is staged without touching the real index.
- `assetutil --info src-tauri/icons/Assets.car` — compiled catalog contains icon images.
- Full npm/Rust validation — existing tests remain green.
- `npm run build -- --bundles app` — Tauri creates a macOS app bundle containing `Assets.car` and `icon.icns`.

## Risks, Tradeoffs, and Open Questions

- `Assets.car` can differ across Xcode versions, so contributors should use Xcode 26+ and review binary changes when toolchains change.
- `git commit --no-verify` bypasses this automation by design; documentation provides the manual fallback.
- The hook modifies and stages a generated file. It prints a message before doing so to avoid silent index changes.
- `actool` embeds build metadata, so byte-for-byte reproducibility across generation times or Xcode versions is not assumed.
